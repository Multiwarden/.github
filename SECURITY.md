# Security policy

Multiwarden handles passwords, passkeys and vault keys, so security reports get priority over
everything else.

## Reporting a vulnerability

**Please do not open a public issue for a security problem.**

Report it privately through GitHub, in the repository it concerns: open the repository's
**Security** tab and choose **Report a vulnerability**.

- Browser extension: [report a vulnerability](https://github.com/multiwarden/clients/security/advisories/new)
- Android app: [report a vulnerability](https://github.com/multiwarden/android/security/advisories/new)
- Website: [report a vulnerability](https://github.com/multiwarden/multiwarden/security/advisories/new)

Please include what an attacker can do, the steps to reproduce it, and the version you tested.
You can expect a first reply within 7 days. The advisory is published, with credit if you want
it, once a fixed version is available.

If the problem is in Bitwarden's own code and the official Bitwarden apps are affected too,
please also report it to Bitwarden through their
[HackerOne program](https://hackerone.com/bitwarden).
