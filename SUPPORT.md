# Getting help

- **Something does not work in Multiwarden:** open an issue in the repository of the app,
  [the browser extension or desktop app](https://github.com/multiwarden/clients/issues/new/choose) or
  [the Android app](https://github.com/multiwarden/android/issues/new/choose).
- **A security problem:** report it privately; see the [security policy](SECURITY.md).
- **Your Bitwarden account, subscription or server:** Multiwarden cannot help with these. Contact
  [Bitwarden support](https://bitwarden.com/contact/).
- **The same problem happens in the official Bitwarden apps:** report it to Bitwarden, in
  [bitwarden/clients](https://github.com/bitwarden/clients/issues) or
  [bitwarden/android](https://github.com/bitwarden/android/issues).

Multiwarden is maintained in spare time, so answers can take a few days.
