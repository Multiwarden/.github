Multiwarden is an unofficial fork of the Bitwarden apps in which every unlocked account takes
part in autofill, saving and passkeys, instead of only the active one. It stays close to
upstream: new behaviour lives in separate files, and Bitwarden's code only gets small, marked
hooks, so every Bitwarden release can be brought in automatically.

| Repository                                                            | What it holds                            |
| --------------------------------------------------------------------- | ---------------------------------------- |
| [multiwarden/clients](https://github.com/multiwarden/clients)         | The browser extension and desktop app    |
| [multiwarden/android](https://github.com/multiwarden/android)         | The Android app                          |
| [multiwarden/multiwarden](https://github.com/multiwarden/multiwarden) | The website, logos and store screenshots |

**Found a bug?** Open an issue in the repository of the app it happens in. **Found a security
problem?** Please report it privately, as described in each repository's security policy.
