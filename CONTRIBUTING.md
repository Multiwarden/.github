# Contributing to Multiwarden

Thanks for helping out. Each repository has its own guide with the details:

- [Browser extension and desktop app](https://github.com/multiwarden/clients/blob/main/.github/CONTRIBUTING.md)
- [Android app](https://github.com/multiwarden/android/blob/main/.github/CONTRIBUTING.md)

For the website ([multiwarden/multiwarden](https://github.com/multiwarden/multiwarden)), fork the
repository, make your change on a branch, check it with `npm run build` in `site/`, and open a
pull request against `main`.

In every repository:

- Open an issue first for larger changes, so no work is wasted.
- Never report security problems in a public issue; see the [security policy](SECURITY.md).
- Contributions are licensed under the GNU GPL v3, like the rest of Multiwarden.
- Everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md).
